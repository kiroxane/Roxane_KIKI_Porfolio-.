# Portfolio développeur

<!-- impeccable:product-schema 1 -->

## Platform

web

## Stack

React, demandé explicitement. TypeScript et Vite proposés pour l'implémentation locale.

## Users

Recruteurs IT et responsables d'équipes techniques évaluant les réalisations d'un développeur.

## Product Purpose

Faire découvrir les projets, permettre de prendre contact et de télécharger le CV.

## Capabilities and Constraints

- Portfolio sur une seule page.
- Navigation horizontale contenant les liens vers les sections, avec ancres dans la page.
- Les projets sont regroupés en professionnels et personnels, selon le classement fourni par l'utilisateur.
- Chaque projet présente une description courte, ses technologies et son lien de code source. Le contexte et la capture sont facultatifs ; les captures seront ajoutées lorsqu'elles seront disponibles.
- Une carte réelle sans capture n'affiche pas d'image de remplacement. Un lien de démonstration n'est ajouté qu'après vérification.
- Bordures et angles arrondis, transitions souhaitées.
- Le livrable initial était le design system : fondations, composants React, documentation et démonstration. Sa page de guide a ensuite été retirée à la demande de Roxane ; le portfolio est la seule surface livrée.
- Couleurs, typographie et espacements délégués à l'assistant pour proposition.

## Product Principles

- Mettre les projets et la contribution personnelle au centre.
- Faciliter le parcours des recruteurs et responsables techniques.
- Préserver une navigation simple sur une page.
- Construire des composants réutilisables à partir des besoins du portfolio.
